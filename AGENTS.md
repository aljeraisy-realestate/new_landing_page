# Repository workflow

- Work on `main`, as requested by the owner. Do not create feature branches unless the owner changes this instruction.
- Commit and push requested deliveries to `origin/main`; never force-push or discard unrelated changes.
- Never commit `.env`, deployment credentials, private route values, database files, or local dependency/build directories.
- Keep the local development server stopped unless the owner asks to start it. Cloud deployment is permitted when explicitly requested.
- The full test suite was previously declined by automatic approval review because of an earlier no-tests instruction. Obtain explicit permission before running the full suite; focused feature checks and production builds have been allowed.
